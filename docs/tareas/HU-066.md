## 4. Alcance

### 4.1 Opciones (SUP-2, SUP-8)
`src/Nilogistic.Aplicacion/Analitica/OpcionesAnalitica.cs`: sección `Analitica` con `string? IdMedicion`. Propiedad calculada `string? IdMedicionValido` que devuelve el ID **solo si cumple `^G-[A-Z0-9]{6,12}$`** (cualquier otro valor, incluido uno con comillas, espacios o `<`, se trata como no configurado y se registra **una** advertencia al arrancar, sin imprimir el valor). **Vacío o inválido = Analytics desactivado** (valor por defecto en Desarrollo, CI y Producción hasta decisión de Jorge). Se registra con `Configure<OpcionesAnalitica>(configuracion.GetSection("Analitica"))`. **No** se añade nada a `appsettings*.json` con un ID real ni a `render.yaml` (el ID se carga como variable de entorno `Analitica__IdMedicion` en Render; lo hace Jorge).

### 4.2 Script y vista (SUP-3)
- **`src/Nilogistic.Aplicacion/wwwroot/js/analitica.js`** (JS vanilla, estilo de `menu.js`, sin dependencias, sin `eval`/`document.write`): lee `document.currentScript.dataset.idMedicion`; vuelve a validar el patrón `^G-[A-Z0-9]{6,12}$` y, si no cumple, no hace nada; define `window.dataLayer` y `function gtag(){dataLayer.push(arguments)}`; inyecta `<script async src="https://www.googletagmanager.com/gtag/js?id=<ID>">`; llama `gtag('js', new Date())` y `gtag('config', ID, { allow_google_signals: false, allow_ad_personalization_signals: false, cookie_domain: window.location.hostname, cookie_flags: 'SameSite=Lax;Secure' })`. No define `user_id` ni envía datos propios.
- **`Views/Shared/_ScriptsAnalitica.cshtml`** (parcial): solo emite `<script src="~/js/analitica.js" asp-append-version="true" data-id-medicion="@id"></script>` cuando `Context.ObtenerConsentimientoCookies().AnaliticaPermitida` es `true` **y** `OpcionesAnalitica.IdMedicionValido` no es nulo (inyecta `IOptions<OpcionesAnalitica>` con `@inject`; la vista no llama a la BLL). En cualquier otro caso no emite nada.
- **`Views/Shared/_LayoutPublico.cshtml`**: `<partial name="_ScriptsAnalitica" />` justo después de `_ScriptsBase`. **Solo** el layout público: los de «Mi cuenta» y panel no cargan Analytics en R1. Las galerías `/diseno/*` heredan el layout público: no deben cargar Analytics (usa `ViewData["SinBannerCookies"] is true` como señal de «página de referencia» o una clave equivalente que ya exista; documenta tu elección en §13).

### 4.3 CSP condicionada al consentimiento (SUP-4)
En `CabecerasSeguridadMiddleware` (inyecta `IOptions<OpcionesAnalitica>`): si `IdMedicionValido` no es nulo **y** la cookie `nl_consent_cookies` de la petición se lee con `PreferenciasCookies.TryLeer` y `Analitica == true` (**sin** consultar versión ni fecha: el middleware no puede llamar a la BLL, y una decisión caducada solo ensancharía la política sin cargar ningún script), la CSP se amplía con:
- `script-src`: `https://www.googletagmanager.com`
- `connect-src`: `https://www.googletagmanager.com https://www.google-analytics.com https://*.google-analytics.com https://*.analytics.google.com`
- `img-src`: `https://www.google-analytics.com https://www.googletagmanager.com`

En cualquier otro caso la CSP es **exactamente la actual** (sin un solo origen de Google). No se toca la CSP de Swagger ni la de `/diseno/correo`. No se agrega `unsafe-inline`.

### 4.4 Retiro del consentimiento (SUP-5)
`CookiesController.Guardar`: cuando la decisión resultante es `analitica = false` (`rechazar_todo` o `guardar` sin la casilla), recorre `Request.Cookies` y, para cada cookie llamada `_ga`, `_gid` o que empiece por `_ga_`, emite `Response.Cookies.Delete(nombre, new CookieOptions { Path = "/", Secure = Request.IsHttps })` (cookies de host exacto, por `cookie_domain` de 4.2). No toca ninguna otra cookie. Con `analitica = true` no borra nada. El resto del comportamiento (303, `returnUrl`, procedencia) no cambia.
