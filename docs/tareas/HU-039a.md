## 2. Objetivo
Dejar en la base el **esquema y los datos iniciales provisionales** que consumen los formularios de alta y la página de Servicios y Membresías: (1) tres catálogos (áreas logísticas, ubicaciones y tipos de contrato) con sus valores, (2) cuatro planes de membresía (Profesional Básico y Premium; Empresa Básica y Plus) con precios, beneficios y límites de prueba, **todos marcados `provisional = true`**. Las tablas están preparadas para que Administración pueda **agregar y editar** valores sin tocar código (sin `DELETE`; se inactivan). La carga es idempotente y se audita con actor «Sistema». Un script lista los registros provisionales para la puerta G6 (RN-056). **No hay pantalla, endpoint, servicio ni repositorio**: la administración de catálogos es HU-061 y la lectura de planes es HU-042.

## 4. Alcance

### 4.1 Migración de esquema (`supabase/migrations/20261109001100_catalogos_y_planes.sql`)
Timestamp mayor que el último (`20261109001000`). Una sola transacción; **idempotente** (la CI la aplica dos veces); mismo rol dueño que las anteriores. Las cinco tablas llevan **columnas base** (Fase 5 B §1.2): `id uuid primary key default gen_random_uuid()`, `activo boolean not null default true`, `creado_utc timestamptz not null default now()`, `actualizado_utc timestamptz not null default now()`, `creado_por uuid null`, `actualizado_por uuid null` (sin clave foránea: aún no existe `identidad.usuarios`), y la convención aprobada **`provisional boolean not null default false`** (D-145).

1. **`app.catalogos`**: `clave text not null` (único, `check (clave ~ '^[a-z][a-z0-9_]*$')`), `nombre text not null check (length(btrim(nombre)) between 1 and 120)`, `provisional`.
2. **`app.catalogo_valores`**: `catalogo_id uuid not null references app.catalogos(id)`, `padre_id uuid null references app.catalogo_valores(id)`, `nombre text not null` (mismo check), `orden int not null default 0`, `provisional`. Índice único **`ux_catalogo_valores_nombre on (catalogo_id, padre_id, lower(nombre)) nulls not distinct`** (PostgreSQL 17: sin `nulls not distinct`, dos valores raíz repetidos pasarían; cubre el borde de nombre duplicado de HU-061). Índice `ix_catalogo_valores_catalogo on (catalogo_id, orden)`.
3. **`app.planes`**: `tipo_cliente text not null check (tipo_cliente in ('profesional','empresa'))`, `nombre text not null` (mismo check), `descripcion text null`, `orden int not null default 0`, `provisional`. Único `ux_planes_nombre on (tipo_cliente, lower(nombre))`.
4. **`app.plan_precios`**: `plan_id uuid not null references app.planes(id)`, `periodicidad text not null check (periodicidad in ('anual','mensual'))`, `moneda char(3) not null check (moneda in ('NIO','USD'))`, `monto numeric(14,2) not null check (monto >= 0)`, `provisional`. Único `(plan_id, periodicidad, moneda)`.
5. **`app.plan_beneficios`**: `plan_id uuid not null references app.planes(id)`, `clave text not null check (clave ~ '^[A-Z][A-Z0-9_]*$')`, `valor text not null`, `unidad text null`, `provisional`. Único `(plan_id, clave)`.
6. **RLS de denegación por defecto** en las cinco tablas y políticas para `nilogistic_app` **por comando** (`select`, `insert`, `update`), cada una precedida de `drop policy if exists`. **Sin política de delete.**
7. **Privilegios:** `revoke insert, update, delete ... from nilogistic_app` y luego `grant select, insert, update` en las cinco (Administración edita cualquier columna). **Sin `delete`** (soft delete con `activo`).
8. **Comentarios** `comment on table/column` en español (incluye qué significa `provisional` y que se retira al validar el valor real, RN-056).
9. Confirma que `scripts/ci/verificar_rls.sql` sigue en verde y réplica local del job `sql` (migraciones ×2). Si algo lo rompe, **no relajes la guardia**: anótalo en «Dudas».

### 4.2 Migración de semilla (`supabase/migrations/20261109001200_semilla_catalogos_planes.sql`)
Una transacción, **idempotente**: cada inserción usa `insert ... select ... where not exists (...)` (o `on conflict do nothing`), nunca duplica y no pisa lo que Administración ya editó (si un valor existe, no se toca, aunque el administrador le haya cambiado el nombre o la marca). Todo registro sembrado lleva **`provisional = true`**.

- **Catálogos** (3): `areas_logisticas` «Áreas logísticas», `ubicaciones` «Ubicaciones», `tipos_contrato` «Tipos de contrato».
- **Valores — áreas logísticas** (6, orden 1 a 6): Transporte; Almacenamiento y distribución; Aduanas y comercio exterior; Compras y abastecimiento; Planificación y cadena de suministro; Servicios generales.
- **Valores — ubicaciones** (17, lista plana con `padre_id` nulo, en este orden): Boaco, Carazo, Chinandega, Chontales, Estelí, Granada, Jinotega, León, Madriz, Managua, Masaya, Matagalpa, Nueva Segovia, Río San Juan, Rivas, Región Autónoma de la Costa Caribe Norte, Región Autónoma de la Costa Caribe Sur. (Sin municipios; el campo `padre_id` queda disponible para ellos más adelante.)
- **Valores — tipos de contrato** (5): Tiempo completo; Tiempo parcial; Por obra o proyecto; Temporal; Pasantía.
- **Planes** (4): `profesional`/«Profesional Básico» (orden 1), `profesional`/«Profesional Premium» (2), `empresa`/«Empresa Básica» (3), `empresa`/«Empresa Plus» (4); `descripcion` nula.
- **Precios** (8): por cada plan, `anual` y `mensual`, moneda `USD`, **monto `0.00`** (no existen los valores reales: tarea #10; el cero es un marcador, no un precio; SUP-2).
- **Beneficios y límites de prueba** (16): por cada plan las claves `MAX_SUBUSUARIOS` (unidad `cantidad`), `MAX_ANUNCIOS_ACTIVOS` (`cantidad`), `DESC_ECOMMERCE_PCT` (`porcentaje`) y `DIAS_PRUEBA` (`dias`), todas con `valor = '0'`.
- **Auditoría del «Sistema»:** si (y solo si) la ejecución insertó alguna fila, escribe **un** asiento en `auditoria.registros` con `tipo = 'gestion'`, `usuario_id = null`, `rol = 'Sistema'`, `accion = 'semilla_catalogos_planes_cargada'`, `entidad = 'app.catalogo_valores'`, `ocurrio_utc = now()` y `detalle` JSON con el número de filas insertadas por tabla. Contar con `get diagnostics ... = row_count` dentro de un bloque `do $$ ... $$`. La segunda ejecución no inserta nada y **no** escribe asiento (E2). Lee `20261109000700` para los campos obligatorios y respeta la partición.
